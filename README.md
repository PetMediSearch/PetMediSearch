# PetMediSearch

## 개요
PetMediSearch는 내 주변 반려동물 약국 / 병원 찾기 서비스 입니다. <br>
데브코스 기간 동안 배운 기술들을 돌아보면서 활용하고자 만든 프로젝트로, <br> 
팀원들의 의견 중 공통된 관심사가 포함된 반려동물과 관련한 서비스를 만들고자 하였으며, <br>
간편로그인API, 지도API를 활용하였습니다.

<br>

<br><br>

## 주요 기능
### 검색
    - 키워드(장소명/주소)가 포함된 검색어를 입력 시 해당하는 정보가 지도 위에 마커 형태로 나타납니다.

<img width="800" alt="searchPlace" src="https://github.com/user-attachments/assets/881237b9-dd7a-4dfc-ac92-3e5d7b13c856">

<br>

    - 전체 / 병원 / 약국 카테고리를 이용해 원하고자 하는 정보만 볼 수 있습니다.
    - '영업 중' 토글을 클릭 해 영업 상태가 '정상'인 장소만 나타나게 할 수 있습니다.
    - 마커 클릭 시 해당하는 장소의 상세 정보를 말풍선 형태의 오버레이로 확인 할 수 있습니다.
    - 회색 마커로 현재 내 위치가 표시됩니다.
